# Scaling-variant generators

The scaling benchmarks (e.g. `hmm_first_order_n02` … `_n14`) exist once per
problem size. The Pluck programs are in `examples/`. These scripts generate the
matching PSI and HyBit programs, one per size of the Pluck sweep:

| Script | Writes | Families |
|---|---|---|
| `generate_scaling_psi.py` | `../psi/*.psi` | changepoint_coal, dawid_skene, hmm_factorial, hmm_first_order, hmm_second_order, king_ei, outliers, secret_ballot, sir_model, soccer, soft_kmeans |
| `generate_scaling_hybit.py` | `../hybit/*.jl` | changepoint_coal, dawid_skene, hmm_factorial, hmm_first_order, hmm_second_order, king_ei, outliers, secret_ballot, sir_model, soft_kmeans |

`scaling_data.json` holds, for every family and size, the exact observations the
Pluck program at that size uses (`data`), the sizes (`values`), file-name
conventions (`filespec`) and the model constants (`constants`). Each generator
embeds that data and those constants, so every system solves the same problem
at each size.

```sh
python3 generate_scaling_psi.py      # write missing programs into ../psi
python3 generate_scaling_hybit.py    # write missing programs into ../hybit
python3 generate_scaling_psi.py --out /tmp/psi --overwrite   # regenerate all elsewhere
```

Existing programs are never overwritten unless `--overwrite` is given. Output is
written without comments, like the rest of `benchmark_translations/`. The scripts
need only Python 3 (standard library).

Families missing from a system cannot be expressed in it. Soccer and the PCFGs use
Dirichlet priors, which HyBit lacks, and PSI cannot express the PCFGs' unbounded
recursion. The SlicStan, Siren and Turing translations already cover every size
and are not generated by these scripts.
