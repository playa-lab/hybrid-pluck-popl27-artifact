           psi:   '-' (no inference line) — use WALL(s) as the comparable number.
           slicstan: WALL(s)=total pipeline (slic+stanc+build+sample); INFER(s)=slic
           +sample (SlicStan->Stan compile + HMC; EXCLUDES the stanc + C++ build that
           are CmdStan overhead). mean(param)+Rhat and the per-component breakdown are
           in the SlicStan timing table above (also logs/slicstan_<name>.log).
STATUS   = ok | TIMEOUT | OOM | ERROR(rc=N) | BAD | ERROR(run)
           | ERROR(slic) | ERROR(stanc) | ERROR(build) | NODATA.
           OOM = SIGKILLed before the timeout = out of memory (the container hit its
           memory limit); WALL is the actual time it ran before dying, not a real
           inference time. Give Docker more memory to measure these.
           slicstan: ERROR(slic) = .slicstan uses a feature SlicStan's DSL lacks;
           ERROR(stanc)/ERROR(build) = its generated Stan is invalid / fails to
           compile (SlicStan codegen); ERROR(run) = HMC could not initialize;
           NODATA = compiles but no slicstan-data/<name>.json.
           BAD = process exited 0 but did not actually infer. For PSI this is
           'Pr[error] = 1' (posterior collapsed, e.g. observing a continuous
           variable at an exact value — measure-zero in PSI's exact semantics).
           A BAD/ERROR/TIMEOUT row's WALL is the single failing run, NOT a real
           inference time — do not compare it against ok rows.
